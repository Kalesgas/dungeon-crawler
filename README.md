# dungeon-crawler

Браузерный рогалик на TypeScript.

Спускайся всё глубже в подземелье, сражайся с монстрами, собирай предметы и попробуй выжить.
Каждый забег уникален: уровни генерируются случайно, а смерть — окончательна.

## Задумка

- **Пошаговый геймплей** — мир двигается только когда ходишь ты.
- **Процедурные подземелья** — комнаты и коридоры генерируются заново на каждом этаже.
- **Бои** — у героя и монстров есть здоровье, атака и защита.
- **Предметы и инвентарь** — зелья, оружие, броня.
- **Прокачка** — опыт за победы, рост характеристик с уровнем.
- **Туман войны** — видно только то, что рядом с героем.
